## 📌 Project Overview

This project focuses on predicting house sale prices using **TensorFlow Decision Forests (TF-DF)**. It treats house price prediction as a **regression problem**, where a machine learning model learns patterns from housing features and estimates property sale prices.

The project is implemented in Python using a Google Colab notebook.

## 🎯 Objectives

- Explore and understand the housing dataset.
- Prepare the data for machine learning.
- Train a regression model with TensorFlow Decision Forests.
- Generate predictions for house sale prices.
- Review model performance using the evaluation approach in the notebook.

## 🧰 Technologies Used

- **Python** – project programming language
- **TensorFlow Decision Forests (TF-DF)** – decision-forest machine learning models
- **Pandas** – tabular data handling
- **NumPy** – numerical operations
- **Google Colab** – notebook development environment

> Add Matplotlib, Seaborn, or other libraries here only if they are used in your notebook.

## ⚙️ Project Workflow

1. **Load the data** – read the housing dataset into the notebook.
2. **Explore the data** – inspect columns, data types, and data patterns.
3. **Prepare features** – process the input data for model training.
4. **Train the model** – build a TF-DF regression model.
5. **Make predictions** – estimate house sale prices.
6. **Evaluate the model** – assess predictions using the metrics included in the notebook.
