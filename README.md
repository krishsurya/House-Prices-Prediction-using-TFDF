
# House Prices Prediction using TFDF

## Project Overview
This project focuses on predicting house sale prices using Machine Learning and TensorFlow Decision Forests (TF-DF).

## Technologies Used
- Python
- TensorFlow Decision Forests (TF-DF)
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
- Load and explore the housing dataset.
- Perform data preprocessing and feature analysis.
- Train a regression model using TensorFlow Decision Forests.
- Predict house sale prices.
- Evaluate model performance.

## Objective
To build a machine learning model that estimates house prices based on available housing features.
